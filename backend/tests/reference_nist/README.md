# Valeurs de référence certifiées du NIST (StRD)

Fichiers téléchargés tels quels le 18/10/2026 depuis le NIST Statistical Reference Datasets
(https://www.itl.nist.gov/div898/strd/). Données publiques du gouvernement des États-Unis. Chaque fichier contient les
données ET les valeurs certifiées : les tests les lisent directement, sans aucune recopie à la main.

| Fichier | Source | Procédure validée |
|---|---|---|
| `Longley.dat` | https://www.itl.nist.gov/div898/strd/lls/data/LINKS/DATA/Longley.dat | régression linéaire (difficulté élevée) |
| `SiRstv.dat` | https://www.itl.nist.gov/div898/strd/anova/SiRstv.dat | ANOVA à un facteur, 5 groupes |
| `AtmWtAg.dat` | https://www.itl.nist.gov/div898/strd/anova/AtmWtAg.dat | ANOVA à un facteur, 2 groupes ; test t de Student (t² = F) |
